\chapter{Conclusion} \label{cap:conclusion}

The test suite covers the main testing categories requested in the assignment: unit tests for business logic, integration tests for third-party providers, REST/API integration tests, concrete-database integration tests, and Selenium end-to-end tests.

The testing decisions prioritize isolation where useful and realism where necessary. Business rules are tested with mocks, provider integrations use simulated HTTP servers, repository behavior is verified with H2, REST behavior runs through the Spring web stack, and the main user journey is validated through a real browser.

The suite also detects current implementation defects. The known defects are intentionally documented and exposed by automated tests, including provider encoding, provider aggregation robustness, iCalendar compatibility, registration validation, overlap validation, and invite response error handling. Once those production bugs are fixed, the same tests can serve as a regression suite for future commits.
